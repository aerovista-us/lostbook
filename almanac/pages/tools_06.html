Light Discipline

Headlamp on full beam all night drains cells before you need to read a map or walk out. Red mode if you have it. Mark the battery drawer in the crate — dead mixed with new has cost us an hour.

  1. Test lights before dark, not after you hear something.
  2. Spare set in a bag inside the bag — sweat kills contacts.
  3. Mirror + light beats light alone for signal (Signals tab).
Sandpoint hardware: lithium cells last longer in cold — worth the trade.
